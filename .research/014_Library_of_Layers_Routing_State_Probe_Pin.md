## TL;DR

LoL is a pretraining architecture whose routed core selects one transformer block per window per depth from a shared library; the paper's load-bearing contributions for THIS stack are two **closed-form runtime halves** of that router: (1) a **supervised linear probe over router outputs** predicts input attributes (safety AUROC 0.92–0.95) with no labels in the LM loss — the selection stream is a free statistic of input semantics; (2) **mode-path extraction + forcing** (mean router probability per depth over labeled logs, pinned per class, forced at inference) controls behavior (~100% strategy adherence) — the path is a control channel, not a correlation. Both transfer to any module-selecting pipeline. **Published prior art already occupies the probe-as-side-channel class** (LoL itself; "Reading, Not Manipulating" arXiv:2610.07774 — router-logit safety detector read at prefill in a serving loop), so this note claims NO literature novelty: the residue is the **transfer + composition** on reflex's engine — a supervised probe over `pick_domain` routing-state features and a report-only pinned-path replay — filed as reflex Issue 107 (PoC, gates pre-registered).

## 1. Paper Core Findings

1. **Architecture.** Prelude (fixed) → routed core (D depths; per WINDOW of W tokens a top-1 linear router selects one block from a library of L blocks) → coda (fixed). Selected expert's residual update scaled by its router probability (loss-free balancing, Wang et al. 2024); Gaussian noise on router logits in training; FiLM per-depth scale/bias; core depth grows over training (1−sqrt schedule, 75% of training — following McLeish et al. loop-scaling).
2. **Windowed causal routing.** Window k's router reads the mean of prior windows' mean hidden states (causality preserved; generation-time information only); window 0 uses a learned per-depth vector + first token. Window boundaries shift by stride S between depths (strided window attention) so information flows between windows; per-token routing is rejected because mixed Q/K projections from different experts train unstably.
3. **Routing paths encode input class.** One-hot expert sequences per window across depths PCA-separate languages; Latin-script languages share paths.
4. **Supervised probe (the sensor).** Ridge regression over router probabilities (per window × all routed depths) predicts sequence harmfulness: AUROC 0.92 (window-level), 0.95 (sequence-level averaged) — trained on a safe/unsafe mix with NO labels in the LM loss.
5. **Path forcing (the actuator).** Per-strategy "mode path" = per-depth argmax of mean router probability over held-out labeled runs (fixes both expert choices and residual weights); forcing it at inference (strategy token replaced by neutral filler) yields ~100% strategy adherence on sudoku (5 strategies, distinct step syntaxes) and mazes (BFS/DFS/A*/bidirectional/dead-end-filling — SAME output syntax, different exploration order). Fixing the path controls the algorithm itself.
6. **The L knob.** Library size L alone interpolates looped-transformer reuse (small L) ↔ MoE sparsity (large L); competitive with dense/looped/MoE at 360M–1B on FLOPs-matched pretraining (17–90 EF per run).
