# Issue 089 — Perm-consistency serving mode: modal selection + disagreement-as-abstention from the Issue-077 perm harness (premise under test)

**Status:** OPEN — T1 measurement first, **near-zero compute** (the existing `perm_probe.json` artifacts from the Bench 128 posture carry NO gold labels and NO top-2 margins, so the margin-null test adds one identity-posture decide pass + a gold-label join — seconds of CPU, no GPU), **with a margin-null baseline**: the premise is under test because the Bench-128 control implies the modelless lane's disagreement is tie-shaped. No serving code before T1 clears the margin-null bar; a T1 miss closes this issue with the numbers.

## Trigger — and the honest inversion (verdict round 1)

The modelless decide path is deterministic — its only sampling axis is the input presentation. Issue 077 (closed, `97b2189`) / Bench 128 built the option-permutation runner (`--perm-probe`, K orderings incl. identity) as an EXCLUSIVE measurement-only mode, gating the control invariant: an untied top pick must never move; median swing ≤ 0.01 pt (the L1 fp envelope). **The control PASSES at 0 flips on the modelless lane (post-fix, five of six suites).** That is exactly why this issue's premise is under test, not assumed: if untied picks never move, then "K orderings disagree" on the modelless engine means "the top-2 scores are exactly tied" — and one decide call already exposes that through its top-2 margin. K× decide calls would add cost and no information. Where real disagreement exists, Bench 128's own record names the lanes: **drex order-biased, agentjev content-bound, laya tail-fragile**, plus typed_decisions' legacy `k == N` positional binding — a real engine DEFECT. Turning a known defect into a confidence feature is backwards; a residual-defect detector belongs with the defect's own repair lineage (the closed-079 lineage), never wired as a gate input.

The open question this issue owns, strictly: **does perm-disagreement carry error-prediction power BEYOND the single-call top-2 margin, on any lane, on untied cases?** If yes on the modelless lane, the serving mode below is designed. If yes ONLY on trained/order-sensitive lanes, **this issue closes as a comparison note inside the published PriDe/self-consistency class** (the deterministic-engine delta is gone); a trained-lane serving mode, if ever wanted, is a NEW issue filed at that point — never a scope extension of this one. If no, this closes as a measurement note and the consensus idea folds into the published class.

## The delta (vs the published classes — the honest novelty scope)

The permutation-averaging family is thoroughly published, for DEBIASING: "LLMs Are Not Robust Multiple Choice" (arXiv:2309.03882, PriDe), "General Permutation Debiasing" (ACL 2024 Findings) — they average predictions across orderings to REMOVE position priors from stochastic LLM scorers. The claimed deltas here are narrow — and **claim-scope-conditional**:

- **Abstention use, not debiasing use:** the disagreement signal would be consumed as a calibrated abstention/escalation feature (Report-the-Floor applies), never to re-weight the pick.
- **Deterministic engine — CONDITIONAL:** self-consistency (arXiv:2203.11171) samples stochastic chains from a generative model. Here ONE deterministic decision path would be re-presented K times. **This delta exists only where the signal is not tie-shaped** — on the modelless lane the Bench-128 control implies it is, so the delta survives only if T1 finds residual margin-independent power there. If T1's signal lives only on stochastic-ish scorers (drex/laya), the claim sits inside the published class and this issue closes as a comparison note.
- **Orthogonality to the existing gate — CONDITIONAL:** corpus-distance asks "is this question in-corpus?"; perm-disagreement asks "does this answer survive a presentation re-draw?" The fusion is only argued for a lane where the stability axis measures something margin does not (T1's finding).
- Signal-diff vs the ESC-depth sibling (recorded in the private escalation research): member-disagreement UQ consumes CROSS-MEMBER disagreement and needs a population; this consumes SAME-MEMBER presentation instability and needs only K decide calls — the zero-training, zero-population version of the same epistemic axis, IF the axis measures anything here.

## Constraints

- **T1 is the gate for everything below.** A margin-null miss closes the issue with the recorded numbers; no serving code is written on a tie-shaped signal.
- **Cost (only if T1 clears):** K× decide per question. Modelless decide p99 ≈ 44 µs (v0.2.4 gates) ⇒ K ≤ 5 stays inside the 1 ms G2 budget. The serving mode is opt-in (`--perm-consensus K`), never default without a GOAT.
- **Majority selection can hurt** ("When Self-Consistency Backfires", OpenReview) — the modal half carries its own per-suite G1; no pooled claim.
- The Bench-128 control law carries regardless: an untied identity-posture pick must equal the modal pick whenever identity is in the modal set — if the mode ever moves an untied pick, that is a finding, not a feature.
- typed_decisions' legacy `k == N` positional binding is a DEFECT lane: any signal measured there routes to the defect's repair (the closed-079 lineage), never into a confidence feature.
