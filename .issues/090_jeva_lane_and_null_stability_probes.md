# Issue 090 — Jeva lane + null/K-stability probe family (from arXiv:2610.18773)

**Status:** OPEN — filed 2026-10-15 from the Jeva distill (rethink-side note: `../riir-rethink/.research/007_Jeva_System_One_First_Principles_Open_Teacher.md`). Comparison-lane + harness-gate work only; serving/product decisions live rethink-side.

Paper: "Jeva: System One Models from First Principles" (Li & Wang, NUS, arXiv:2610.18773) — open decision-native model (HF `LIQIIIII/Jeva-4B`, code Apache-2.0 at `LiQiiiii/Jeva`). Three structural propositions double as pin-able properties for our engine, and the model is the first same-wire (choice/noul/score) open-weights lane candidate with a published implementation.

## A — Probe family (the paper's propositions as our gates)

- [ ] **A1 — K-scaling null-stability probe** (`--null-probe`): their Prop 2 proves a flat softmax-with-null null-probability carries an explicit −log K term that a max-based coverage gate `ρ = σ((max_i s_i − b_cov)/τ_cov)` removes. ⚠ Removing the TERM is not immunity: the max of K option scores still rises with K, so abstention drift remains possible as K grows — for their gate and for ours alike. That drift is exactly what the probe measures. Probe: answer each question with 0/8/32/256 graded-similarity decoy options appended; assert null/abstain drift ≤ ε per lane (or characterize + pin the drift curve if a flat ε proves wrong). Include the Report-the-Floor leg: abstention AUROC/ECE of the gate must beat the conformal-naive floor (Plan 340 shape) or the gate FAILS.
- [ ] **A2 — decoy set-preference probe**: their Prop 1 — a decider whose option dependence is only through independent per-option scores cannot REVERSE the A-vs-B preference when the candidate set changes (their softmax form: the shared denominator cancels in the ratio; our form: monotone independent scores ⇒ the ordering is decoy-invariant a fortiori). Pin it — assert the RELATIVE ORDER of A and B, `sign(s_A − s_B)`, is identical across {A,B}, {A,B,+8 decoys}, {A,B,+64 decoys}; flip rate ≤ ε per suite. The OVERALL pick may legitimately change (a decoy can win the argmax at K=64) — that is not a failure. A red means an order/set-sensitive feature leaked into scoring — structural fix, never smoothing.
- [ ] **A3 — noul-conditional probe**: their Noul readout is the positive candidate's CONDITIONAL probability q_{i+}, never the joint ρ·q_{i+} (the joint drifts with coverage, hence with K). Probe: the noul value for the same question is invariant under decoy augmentation (≤ ε); the probe separates conditional-shaped from joint-shaped readouts and pins which shape each lane ships.
- [ ] **B2 — perm-probe 0-flip floor + structural-repair rule**: lanes claiming option-text independence (no position/index/question echo in the option representation) pin 0.00% order flips; a red lane gets the structural repair (strip the order-sensitive feature), never average-over-permutations. Their measured row: 0.00% flips, mean TV 3.17e-8, no order-consistency loss — the target shape.
- [ ] **C1 — (low) rubric-covariance + template probes**: score = Σ q_i·v_i identities (v→10v scales ×10; v→v+c shifts c·Σq; argmax value-blind) to fp tolerance; option-template type presence vs corpus-route agreement (state route == option routes).

## C — Follow-up (fusion idea, novelty TBD)

- [ ] **C2 — modelless set-refinement operator** (katgpt-core, flag-gated `set_refine`): their Prop 1 shows the one capability an independent scorer structurally lacks is set-dependent preference reversal; their fix is one candidate-conditioned attention block. Modelless analog to price: `x' = x ⊕ g·Σ_i w_i·k_i` with sigmoid-gated kernel weights `w_i = σ(dot(x, k_i)/τ)` (never softmax), options immutable. **Invariance scope is NOT A1–A3:** set-dependent reversal REQUIRES option interaction (their Prop 1), so a working `set_refine` deliberately BREAKS A2 by design and may move A1/A3 wherever coverage reads refined scores. What it preserves: permutation invariance (B2 — the Σ over options is order-symmetric) and value-blind argmax (C1). A `set_refine` lane is therefore EXEMPT from A2 and gated instead by its own set-awareness suite. Needs that probe suite + GOAT (flag-on beats flag-off beyond the conformal floor; G3 hash-identity flag-off; G2/G4 at `--release`) before any plan. Do not wire blind.
